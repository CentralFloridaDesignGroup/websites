# Purpose of Plan

This plan involves reviewing the current status of `WHITEPOINTSURVEY_V4` as a mono-repo. This repo was created early in my understanding of typescript, monorepos, and web development. As such, there are many issues, complications, and other improvements that can only reasonably be made by updating this repo with new packages and sites and sun-setting the older versions once the new versions are in effect.

## Goal

The goal of this plan is to transition all packages to `V5`, a cleaner, leaner, more elegant solution to the existing codebase. In effect, we are trimming fat, rewriting code, and getting better understandings of it's systems. It is not the intent to have AI or agents do everything, rather I will write the majority of code with the AI's assistance with questions and the occasional snippet.

# The goods

I believe the UI for the documents website was decent. The homepage, especially, was a good rendition. The features designed thus far are good, useful features.

# The bads 

Towards the end of V4, I let AI do the majority of changes. This ultimately hurt my understanding of this project to the point I cannot fully explain how it works. This is bad since sensitive topics are handled, manipulated, and processed in this repo.
