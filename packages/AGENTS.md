# Purpose

The purpose of this folder is to contain all shared `components`, `scripts`, `types`, `interfaces`, and `constants` for use within each other and `sites`.
Each folder within `cfdg` contains further instructions on what the package is used for. This is strictly for `version 5`.
If you are unsure what item should go where, ask for clarification from the user.

- Industrial refers to items aimed primarily to the internal documentation.
- Branding refers to items aimed primarily to the public-facing websites.
- Core is what both industrial and branding build off of.
