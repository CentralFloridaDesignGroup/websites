# CXL Code List Editor — Disclaimer

This tool generates `.cxl` point-code-library files for **CHC LandStar** field data collection software. Please read before using it.

## Unofficial tool

This editor is **not** provided by, affiliated with, or endorsed by CHC Navigation, Huace, or the LandStar app. The `.cxl` file format was reverse-engineered by inspecting a real exported file — it is not built from official vendor documentation, and there is no guarantee it covers every rule the LandStar app enforces.

## Test before you rely on it

Always import a generated file into LandStar (or have someone who can) and confirm it behaves as expected **before** relying on it for real fieldwork. Do not use a freshly generated code list on an active project without verifying it first.

## Custom symbols are out of scope for now

This version of the tool only offers LandStar's built-in symbol glyphs. Support for referencing and managing custom symbols is planned for a future update — see the in-app notes on symbol portability if you're already familiar with LandStar's custom-symbol import flow.

## No sensitive data

This is a publicly accessible tool. Don't enter proprietary project information, client data, or anything sensitive into a code list built here.

By continuing, you acknowledge the above and accept responsibility for verifying any file generated by this tool before using it in the field.
